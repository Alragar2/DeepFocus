# DeepFocus 🍅

A minimalist, distraction-free productivity application featuring Pomodoro timers, task organization, project management, and activity tracking. Built to help you achieve deep work and maintain focus.

## Features ✨

- **Pomodoro Timer**: Customizable focus sessions, short breaks, and long breaks with precise timing.
- **Task Management**: Organize and prioritize your daily tasks efficiently.
- **Project Organization**: Group tasks by projects to maintain clarity and structure.
- **Activity Tracking**: Monitor your productivity and completed sessions over time.
- **Internationalization (i18n)**: Seamless support for both English and Spanish locales.
- **Dynamic Title**: Real-time remaining time updates directly in your browser tab during active sessions.

## Tech Stack 🛠️

- **Framework**: [Next.js](https://nextjs.org/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Language**: TypeScript

## Getting Started 🚀

First, clone the repository and install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application in action.
